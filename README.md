# CapsSwitch

Маленькая программа для Windows 10/11 (x64): переключает раскладку клавишей CapsLock.

| Клавиши | Что делает |
|---|---|
| **CapsLock** | следующая раскладка (RU ↔ EN; если раскладок больше двух, по кругу) |
| **Shift + CapsLock** | обычный CapsLock (заглавные буквы) |

Размер около 25 КБ. Нет окна и значка в трее. Не нужны AutoHotkey, .NET и прочие зависимости.

## Установка

1. Скачайте `CapsSwitch.msi` и запустите его. Windows попросит права администратора.
2. Программа запустится сразу. При следующих входах в Windows она будет стартовать сама.

Установщик не подписан, поэтому Windows может показать окно «Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**.

## Удалённый доступ и виртуальные машины

Поставьте CapsSwitch на оба компьютера. Если активно окно удалённого доступа (RDP, AnyDesk, TeamViewer, RustDesk, Parsec, VNC и др.) или виртуальной машины (Hyper-V, VirtualBox, VMware), локальная копия отдаёт CapsLock удалённому компьютеру без изменений. Раскладку тогда переключает копия на удалённой стороне.

## Удаление

Откройте «Параметры» → «Приложения» → **CapsSwitch** → «Удалить». Программа остановится, а автозапуск будет снят.

## Как это устроено

- Перехват клавиатуры сделан через `WH_KEYBOARD_LL`. Нажатие CapsLock без Shift поглощается, и активному окну отправляется `WM_INPUTLANGCHANGEREQUEST` со следующей раскладкой из `GetKeyboardLayoutList`.
- Shift+CapsLock программа пропускает дальше без изменений, и Windows переключает CapsLock как обычно.
- Автозапуск устроен как задача Планировщика `CapsSwitch`: она срабатывает при входе любого пользователя и запускается с наивысшими доступными правами. Поэтому переключение работает и в окнах, открытых от имени администратора. Обычная запись в автозагрузке такого не позволяет.
- Установщик вызывает `CapsSwitch.exe --install` (регистрирует задачу) и `--uninstall` (останавливает программу и удаляет задачу). Чтобы просто остановить программу, есть `CapsSwitch.exe --quit`.

## Сборка

Собирается на Linux (Ubuntu/Debian):

```bash
sudo apt-get install -y gcc-mingw-w64-x86-64 wixl
./build.sh          # → build/CapsSwitch.exe, build/CapsSwitch.msi
```

GitHub Actions собирает MSI на каждый push. Если поставить тег `v*`, MSI попадёт в Releases.

## Новая версия

Поднимите версию в `installer/CapsSwitch.wxs`: атрибут `Version` у `Product` и `Maximum` у `UpgradeVersion`. Тогда новый MSI сам удалит старую версию.
